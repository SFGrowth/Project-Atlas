# DARWIN Daily Research Queue Specification

**Version:** 1.0.0
**Created:** 2026-07-31T01:18:00Z
**Sprint:** darwin-complete-edge-search-universe
**Status:** PRE-REGISTRATION

---

## 1. Purpose

Each market day, DARWIN produces a structured daily hypothesis queue and a human-readable research report. These are the primary audit trail for DARWIN's autonomous research activity.

---

## 2. Output Files

| File | Format | Description |
|---|---|---|
| DARWIN_DAILY_HYPOTHESIS_QUEUE_YYYY_MM_DD.json | JSON | Machine-readable daily queue |
| DARWIN_DAILY_HYPOTHESIS_REPORT_YYYY_MM_DD.md | Markdown | Human-readable research report |

Both files are generated by the `DARWIN Daily` cron job at 21:45 UTC on weekdays.

---

---

## 4. Daily Report Required Sections

The Markdown report must answer all of the following:

| Question | Required |
|---|---|
| WHAT DID DARWIN NOTICE? | Live observations and anomalies |
| WHAT HYPOTHESES DID IT CREATE? | New hypotheses with IDs and rationale |
| WHY WERE THEY PRIORITISED? | Priority scores and reasoning |
| WHAT WAS TESTED? | Experiments run today |
| WHAT FAILED? | Rejected findings with reasons |
| WHY DID IT FAIL? | Rejection reason codes |
| WHAT REMAINS INCONCLUSIVE? | Inconclusive findings with next steps |
| WHAT LOOKS PROMISING? | Promising findings with metrics |
| WHAT WILL BE TESTED NEXT? | Top 3 queued hypotheses |
| WHICH FAMILIES ARE UNDER-RESEARCHED? | Starvation risk families |

---

## 5. Archival

Daily queue files are committed to the sprint branch by the `Daily Report + CRO` cron job at 22:00 UTC. The GitHub archival proof is recorded in the sprint evidence.

---

## 6. Dashboard Integration

The daily queue is displayed on the Atlas Nexus dashboard under the `DAILY RESEARCH REPORT` panel. The dashboard reads directly from the `darwin_daily_hypothesis_queue` table. No hardcoded evidence is permitted.
