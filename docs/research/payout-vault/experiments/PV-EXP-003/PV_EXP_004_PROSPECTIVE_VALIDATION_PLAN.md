## 1. Background

PV-EXP-003 identified that excluding Monday trades from the Payout Vault setup
produces a positive improvement in expectancy. This was classified as
**RETROSPECTIVE_DISCOVERY + INTERNAL_TEMPORAL_VALIDATION** — the Monday exclusion
was discovered and tested using the same 152-trade historical population (Oct 2025
– Jul 2026). The 60/40 chronological split provides internal temporal validation
only, not prospective validation.

**Corrected PV-EXP-003 numbers (post G12 correction sprint):**

| Metric | Baseline (152 trades) | F2 Filtered (118 trades) |
|---|---|---|
| Expectancy | +$12.32/trade | +$24.79/trade |
| Profit Factor | 1.27 | 1.56 |
| Win Rate | 30.9% | 32.2% |
| Training expectancy | +$5.50 | +$12.13 |
| Validation expectancy | +$22.49 | +$44.60 |

The validation half (+$44.60) substantially exceeds the training half (+$12.13),
which is consistent with the filter capturing a genuine effect rather than
overfitting to the training data. However, both halves were drawn from the same
historical population, so this is not a true prospective test.

## 2. Hypothesis

> Excluding Monday trades from the Payout Vault setup produces a statistically
> significant improvement in expectancy in a prospective out-of-sample population
> (bootstrap 95% CI lower bound > −$10, permutation p < 0.10).

**Null hypothesis:** Monday exclusion produces no improvement in expectancy in
the prospective population (H₀: expectancy_filtered ≤ expectancy_baseline).

## 4. Data Collection Protocol

### 4.1 Prospective Population

All Payout Vault events generated by the live webhook **after the date this plan
is committed to GitHub** are prospective. Events generated before that date are
historical and must not be included in the prospective population.

The plan commit date is the **information cutoff** for PV-EXP-004. Any event
whose `information_cutoff` timestamp is before the plan commit timestamp is
historical and excluded from the prospective population.

### 4.2 Minimum Sample Size

The minimum sample size is **50 filled non-Monday trades**. Based on the
historical rate of 118/152 = 77.6% non-Monday trades, this requires approximately
64 total filled trades, or roughly 3–4 months of live data at the current fill
rate (~16 trades/month).

**Estimated completion:** October–November 2026 (if fill rate holds).

### 4.3 Monday Trades

Monday trades are still taken in live trading — they are not excluded from
execution. The filter is applied analytically: Monday trades are tracked
separately and excluded from the F2 performance calculation. This avoids
selection bias in the prospective sample.
